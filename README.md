# JSON Field Explorer

A modern, interactive web-based tool for exploring and modifying JSON structures with an intuitive user interface.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ Features

- 🎨 Modern, clean interface with dark mode support
- 🔍 Interactive field exploration and modification
- ⚡️ Real-time JSON preview with syntax highlighting
- 📝 JSON Schema validation support
- ⌨️ Keyboard shortcuts for improved productivity
- 🔄 Undo/Redo functionality
- 🔎 Field search capabilities
- 📋 One-click JSON copying
- 🎯 Drag-and-drop field reordering
- 🌐 Fully client-side - no server required

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/json-field-explorer.git
```

2. Open `index.html` in your web browser

That's it! No build process or server required.

## 🎮 Usage

1. Paste your JSON in the input area
2. Explore and modify fields in the interactive panel
3. Use the search feature to find specific fields
4. Copy the modified JSON with one click
5. Toggle dark mode for comfortable viewing
6. Validate against JSON Schema when needed

### ⌨️ Keyboard Shortcuts

- `⌘ + C` / `Ctrl + C`: Copy JSON
- `⌘ + Z` / `Ctrl + Z`: Undo
- `⌘ + F` / `Ctrl + F`: Search Fields
- `⌘ + D` / `Ctrl + D`: Toggle Dark Mode

## 🛠️ Technologies Used

- Vanilla JavaScript (ES6+)
- Tailwind CSS for styling
- highlight.js for syntax highlighting
- Sortable.js for drag-and-drop functionality
- Lucide Icons for UI elements
- Ajv for JSON Schema validation

## 📦 Dependencies

All dependencies are loaded via CDN:
